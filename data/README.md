* **Dataset name:** Satellite Image Classification
* **Dataset source:** [Kaggle](https://www.kaggle.com/datasets/mahmoudreda55/satellite-image-classification)
* **Number of images:** 5,631 total images
* **Number of classes:** 4 classes (`cloudy`, `desert`, `green_area`, `water`)
* **Images per class:**
  * `cloudy`: 1,500 images
  * `green_area`: 1,500 images
  * `water`: 1,500 images
  * `desert`: 1,131 images
* **Example images:** Sample RGB satellite imagery depicting distinct land cover and atmospheric categories (e.g., body of water surfaces, arid desert terrain, dense forest/vegetation, and cloud coverage).
* **Image dimensions:** 256 × 256 pixels (RGB / 3 channels) -> we convert it into 128 × 128 pixels
* **Any class imbalance:** Minor class imbalance (three classes have exactly 1,500 images each, while the `desert` class has 1,131 images, representing ~20% of the total dataset).
